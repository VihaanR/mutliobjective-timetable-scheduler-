Faculty / Branch / Allocation Dashboard

Backend-backed setup screen for the timetable engine

Main UI Generate UI ⚡ Evolution My Timetable

Faculty

Add teachers here. These IDs are used in allocations and timetable generation.

Branches

Branches group divisions and courses. Divisions are created through the branch API.

Divisions

Class sections (D1, D2…) inside a branch. Each splits into two batches for labs; leave batch names blank to default to D11 / D12.

Subjects

Per-branch courses. Sessions/week drive the timetable: each practical becomes a 2-hour batch-split lab. At least one of theory/practical/tutorial must be > 0.

Allocations

Map a division × subject to its teacher. Pick a subject with practicals and the two batch-faculty pickers appear automatically (the two lab halves run simultaneously in different labs).

Rooms

Shared across every branch. Lectures are scheduled only in classrooms and labs only in labs, so you need at least two labs for batch-split practicals.

Weekly slot grid

One institutional grid (Mon–Fri × periods). Use the generator to build a standard day, then Save — saving replaces the whole grid.

🏫 Room & Lab Availability Finder

Check unoccupied classrooms and labs for any selected date and timeslot.
